# Cold Mountain model ranking video

15-second, 1920 × 1080 Remotion composition presenting the total ranking of the nine evaluated model implementations.

## Commands

```bash
npm install
npm run lint
npm run dev
npm run render
```

The composition ID is `ModelRanking`. Generated media is written to `out/` and is intentionally ignored by Git.

The displayed scores mirror `../data/results.json`. Update `src/data.ts` whenever the report scoring changes.
