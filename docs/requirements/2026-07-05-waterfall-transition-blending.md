# Waterfall Transition Blending / 瀑布衔接过渡

## Requirement / 需求

English: Soften the visual transition between the outlet stream and the waterfall.

中文：柔化出口溪流与瀑布之间的视觉衔接。

## Summary / 概要

English: The outlet stream now fades and lightens near the waterfall lip, and a broken foam overlay covers the lip area so the river-to-waterfall boundary no longer reads as a hard rectangular cut.

中文：出口溪流现在会在瀑布口附近淡出并变浅，同时瀑布口增加破碎泡沫覆盖层，让河流到瀑布的边界不再像生硬的矩形切口。

## User Request / 用户需求

English: The user said the river and waterfall now connect, but the transition is too hard and needs color and range blending.

中文：用户说明河流和瀑布现在连接没问题，但衔接太生硬，需要颜色和范围上的过渡。

## Scope / 范围

English: Update only the visual transition at the waterfall lip: outlet stream endpoint fade/color blending and a small foam overlay. Do not change river path, waterfall placement, terrain carving, lake geometry, downstream river geometry, vegetation, player behavior, lighting, textures, or unrelated pending work.

中文：仅更新瀑布口视觉过渡：出口溪流末端淡出/颜色混合，以及小范围泡沫覆盖层。不改变河流路径、瀑布位置、地形雕刻、湖泊几何、下游主河道几何、植被、玩家行为、灯光、贴图或无关待提交改动。

## Acceptance Criteria / 验收标准

English:
- The outlet stream fades and lightens as it reaches the waterfall lip.
- A broken foam/mist overlay covers the lip transition area.
- The hard rectangular edge between stream and waterfall is visually reduced.
- The project build passes.

中文：
- 出口溪流到达瀑布口时逐渐淡出并变浅。
- 瀑布口过渡区域有破碎的泡沫/薄雾覆盖。
- 溪流与瀑布之间的矩形硬边明显减弱。
- 项目构建通过。
