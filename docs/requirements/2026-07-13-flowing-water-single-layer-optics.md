# Flowing Water Single-Layer Optics / 流动水体单层光学

## Requirement / 需求

为 Balanced 与 Quality 质量档位增加基于场景颜色和场景深度的单层流动水光学。渲染流程必须先由 Base 无水通道生成不含任何水体的场景颜色与深度，再由 WaterComposite 通道复制该结果并统一绘制全部水体；仅流动水材质可以采样无水场景颜色与深度，以 Beer-Lambert RGB 吸收、散射和小幅屏幕空间折射表现水下厚度。Performance 档位必须关闭该光学路径并保留现有回退渲染。

Add scene-color- and scene-depth-based single-layer optics to the Balanced and Quality presets. The render pipeline must first produce scene color and depth without any water in a Base pass, then copy that result and draw every water body together in a WaterComposite pass. Only flowing-water materials may sample the water-free scene color and depth to represent underwater thickness with Beer-Lambert RGB absorption, scattering, and subtle screen-space refraction. The Performance preset must disable this optics path and retain the existing fallback rendering.

## Summary / 概要

阶段二只扩展流动水体的合成与着色路径。Balanced 和 Quality 使用带有两个独立深度纹理的颜色/深度 ping-pong 渲染目标：Base 无水通道隐藏所有水体根节点并写入当前基础颜色与深度，WaterComposite 通道把该颜色与深度复制到输出目标后，按现有顺序绘制流动河水、静态湖面、瀑布、泡沫和水雾。流动水根据折射后的无水场景采样、线性场景深度与水面深度差计算光程，并应用逐 RGB 通道的 Beer-Lambert 透射及受限散射；其他水体只为保持遮挡与透明排序而进入同一通道，其材质不变。Performance 不创建或执行阶段二水体合成路径。

Phase two extends only flowing-water composition and shading. Balanced and Quality use color/depth ping-pong render targets whose two sides own distinct depth textures. The water-free Base pass hides every water root and writes the current base color and depth. WaterComposite copies that color and depth into its output target, then draws flowing rivers, static lakes, waterfalls, foam, and mist in their existing order. Flowing water derives optical distance from a subtly refracted water-free scene sample and the difference between linearized scene depth and water-surface depth, then applies per-channel Beer-Lambert transmission and bounded scattering. Other water types enter the same pass only to preserve occlusion and transparent ordering; their materials remain unchanged. Performance neither creates nor executes the phase-two water-composition path.

## User Request / 用户需求

用户希望在现有微表面光照基础上继续提升河流的通透感、厚度感和光感，并要求技术实现不限于既有 river-creator 方法。阶段二明确采用业界常见的 single-layer water 合成思路：Balanced 与 Quality 通过无水底图、场景深度、RGB 吸收/散射及轻微折射改善流动水；Performance 关闭该效果。此次范围不得修改水体几何，也不得改变静态湖面或瀑布材质。

The user wants to build on the existing microfacet lighting with greater clarity, depth, and light response in rivers, without limiting the implementation to prior river-creator techniques. Phase two explicitly adopts a common single-layer-water composition approach: Balanced and Quality improve flowing water with a water-free base image, scene depth, RGB absorption/scattering, and slight refraction, while Performance disables the effect. This phase must not change water geometry or alter static-lake or waterfall materials.

## Scope / 范围

- Performance 档位关闭阶段二单层光学，继续使用现有水体渲染回退；不得为该档位创建、绑定或采样场景颜色/深度水体缓冲，也不得增加阶段二合成通道。 / The Performance preset disables phase-two single-layer optics and continues to use the existing water-rendering fallback; it must not create, bind, or sample scene color/depth water buffers or add the phase-two composition pass.
- Balanced 与 Quality 档位使用 `Base` 无水通道和 `WaterComposite` 通道。`Base` 在保持非水场景既有绘制行为的前提下隐藏全部水体根节点；`WaterComposite` 先保留 Base 颜色与深度，再绘制全部水体。 / The Balanced and Quality presets use a water-free `Base` pass and a `WaterComposite` pass. `Base` hides every water root while preserving existing non-water scene rendering; `WaterComposite` first preserves the Base color and depth, then draws every water body.
- 合成器的两个 ping-pong 渲染目标必须各自拥有独立的深度纹理，并与各自颜色纹理同步交换和缩放；不得在两个 framebuffer 之间共享同一个深度纹理，也不得缓存某一帧固定的读缓冲。 / Both ping-pong render targets in the composer must own distinct depth textures that swap and resize with their corresponding color textures. A single depth texture must not be shared between framebuffers, and a fixed read buffer from one frame must not be cached.
- `WaterComposite` 必须从当帧 Base 结果复制颜色与深度，再以复制后的深度进行水体遮挡测试。全部流动河水、静态湖面、瀑布水帘、泡沫和水雾仍在这个 water pass 中统一绘制，并保留现有 `renderOrder`、透明混合及相互遮挡语义。 / `WaterComposite` must copy color and depth from the current frame's Base result, then use the copied depth for water occlusion testing. All flowing rivers, static lake surfaces, waterfall curtains, foam, and mist remain unified in this water pass, preserving their existing `renderOrder`, transparent blending, and mutual occlusion semantics.
- 只有共享流动水材质获得并采样当帧无水场景颜色、场景深度、分辨率和相机深度参数。静态湖面、瀑布、泡沫与水雾不得新增这些采样，不得改写其 shader、混合方式或视觉参数。 / Only the shared flowing-water material receives and samples the current frame's water-free scene color, scene depth, resolution, and camera-depth parameters. Static lakes, waterfalls, foam, and mist must not gain these samples or have their shaders, blending modes, or visual parameters changed.
- 流动水以线性化后的无水场景深度减去水面深度得到非负的可见光程，并对吸收系数执行逐 RGB 通道的 Beer-Lambert 透射 `T = exp(-sigmaA * distance)`；吸收后的场景颜色与受限的水体散射颜色合成，浅水保持较高透射，较深水逐渐呈现水体自身色调。 / Flowing water derives a non-negative visible optical distance by subtracting water-surface depth from linearized water-free scene depth and applies per-channel Beer-Lambert transmission, `T = exp(-sigmaA * distance)`. The attenuated scene color is combined with bounded water scattering so shallow water remains more transmissive while deeper water gradually takes on the water body's own tint.
- 折射只允许对无水场景颜色和深度 UV 施加由现有流动法线驱动的小幅屏幕空间偏移；偏移必须受限，并在越界、无有效背景深度或深度关系无效时安全回退到未偏移采样，避免岸边拉伸、前景泄漏和明显热浪感。 / Refraction may only apply a subtle, bounded screen-space offset driven by the existing flowing normal to water-free scene color and depth UVs. Out-of-bounds coordinates, missing valid background depth, or invalid depth relationships must safely fall back to the unrefracted sample to prevent shoreline stretching, foreground leakage, and an obvious heat-haze appearance.
- 单层光学结果必须在流动水 shader 内完成颜色合成，避免对预合成背景再次进行普通透明混合；阶段二之后的既有 GTAO、颜色处理、抗锯齿及输出流程保持原有职责和顺序。 / The single-layer optical result must be color-composited inside the flowing-water shader so the precomposited background is not subjected to ordinary transparency blending a second time. Existing GTAO, color processing, anti-aliasing, and output stages after phase two retain their current responsibilities and order.
- 不修改河流、交汇、岸线、河床或任何水体网格，不新增水体对象、纹理或几何属性；不修改流向生成、碰撞、玩法水体采样、静态湖面材质或瀑布相关材质。 / Do not modify river, junction, bank, riverbed, or any other water geometry; add no water objects, textures, or geometry attributes. Do not modify flow generation, collisions, gameplay water sampling, static-lake materials, or waterfall-related materials.

## Acceptance Criteria / 验收标准

- Performance 下不存在活动的 Base 无水加 WaterComposite 阶段二路径，流动水不读取场景颜色或场景深度，现有回退外观和水体绘制顺序无回归。 / Under Performance, no active phase-two water-free Base plus WaterComposite path exists, flowing water does not read scene color or scene depth, and the existing fallback appearance and water draw order show no regression.
- Balanced 与 Quality 下，Base 输出不包含任何水体，WaterComposite 从当帧当前读缓冲复制完整颜色与深度后再绘制全部水体；静态湖、瀑布、泡沫和水雾在合成后仍可见且维持既有先后关系。 / Under Balanced and Quality, the Base output contains no water, and WaterComposite copies complete color and depth from the current frame's current read buffer before drawing every water body. Static lakes, waterfalls, foam, and mist remain visible after composition and retain their existing ordering relationships.
- 合成器的读写目标持有两个不同的深度纹理；窗口缩放、设备像素比变化或动态分辨率变化后，每个深度纹理仍与对应颜色纹理尺寸一致，且没有 framebuffer feedback、incomplete attachment 或跨帧错配。 / The composer's read and write targets hold two different depth textures. After window resizing, device-pixel-ratio changes, or dynamic-resolution changes, each depth texture still matches its corresponding color texture, with no framebuffer feedback, incomplete attachment, or cross-frame mismatch.
- 只有流动水 shader 声明并实际读取场景颜色/深度光学输入；静态湖面和瀑布相关材质的 shader、uniform、混合设置与视觉输出未被阶段二修改。 / Only the flowing-water shader declares and actively reads scene color/depth optical inputs. Static-lake and waterfall-related material shaders, uniforms, blending settings, and visual output are unchanged by phase two.
- 流动水实际使用逐 RGB 通道的 Beer-Lambert 透射和散射合成：浅水能辨认水下场景，光程增加时红、绿、蓝通道按各自系数连续衰减并逐渐转向受限水色；结果无负光程、NaN、无穷值或突变色带。 / Flowing water actively uses per-channel Beer-Lambert transmission and scattering composition: underwater scenery remains recognizable in shallow water, while increasing optical distance continuously attenuates red, green, and blue by their respective coefficients and trends toward a bounded water tint. The result contains no negative optical distance, NaNs, infinities, or abrupt color bands.
- 折射幅度保持克制并随现有流动法线运动；河岸、岩石和植被边缘没有明显拉伸、重复轮廓、前景穿透或热浪式扭曲，异常 UV/深度样本稳定回退到未折射结果。 / Refraction remains subtle and moves with the existing flowing normal. Banks, rocks, and vegetation edges show no obvious stretching, duplicate contours, foreground bleed-through, or heat-haze distortion, and invalid UV/depth samples stably fall back to the unrefracted result.
- 主河、汇流、低地溪流、湖泊出口与瀑布邻近河段均显示连续的厚度与透射变化；静态湖面、瀑布水帘、泡沫、水雾、水体几何及玩法水体逻辑无视觉或行为回归。 / The main river, junctions, lowland creeks, lake outlet, and river segment near the waterfall all show continuous thickness and transmission variation. Static lakes, waterfall curtains, foam, mist, water geometry, and gameplay water logic show no visual or behavioral regression.
- `npm test`、`npm run build`、`npm run check:lowlands` 和 `git diff --check` 均通过，且代码差异仅覆盖阶段二渲染合成和流动水光学所需范围以及本需求文档。 / `npm test`, `npm run build`, `npm run check:lowlands`, and `git diff --check` all pass, and the code diff is limited to the phase-two render composition and flowing-water optics required by this document, together with this requirement document.
