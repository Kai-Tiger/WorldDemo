# FPS HUD / 帧率显示

## Requirement / 需求

English: Show the real-time frame rate in the top-left game HUD.

中文：在游戏左上角 HUD 中显示实时帧率。

## Summary / 概要

English: The existing HUD now includes an FPS row, updated from the animation loop using `requestAnimationFrame` timing without adding a new dependency.

中文：现有 HUD 新增 FPS 行，通过动画循环中的 `requestAnimationFrame` 时间戳更新，不新增依赖。

## User Request / 用户需求

English: The user asked to implement a real-time frame rate display in the top-left corner.

中文：用户要求在左上角实现实时帧率显示。

## Scope / 范围

English: Add only a lightweight FPS readout to the existing HUD. Do not add external performance libraries, alter rendering behavior, change gameplay logic, or modify unrelated UI.

中文：仅在现有 HUD 中新增轻量 FPS 显示。不添加外部性能库、不改变渲染行为、不修改玩法逻辑或无关 UI。

## Acceptance Criteria / 验收标准

English:
- The top-left HUD displays an `fps` value.
- The value updates continuously during rendering.
- Existing position readouts and render toggles still work.
- Build verification passes.

中文：
- 左上角 HUD 显示 `fps` 数值。
- 数值在渲染过程中持续更新。
- 现有坐标显示和渲染开关仍可正常工作。
- 构建验证通过。
