# Blender Gravel Patch Meshes / Blender 碎石 Patch 网格

## Requirement / 需求

Replace the flat gravel overlay look with reusable Blender-authored gravel patch meshes that provide real low-profile stone geometry.

将扁平碎石覆盖层的观感替换为可复用的 Blender 碎石 patch 网格，用真实低矮石子几何提供体积感。

## Summary / 概要

The gravel overlay now loads modular `.glb` gravel patch assets generated by Blender and places them as instanced meshes around the player. The generated assets use Blender X/Y as the patch plane and Z as pebble height so the meshes lie on the terrain instead of standing upright. The patches align to terrain height and normal, use deterministic placement, and avoid rivers, water-system areas, and small lakes.

碎石覆盖层现在会加载由 Blender 生成的模块化 `.glb` 碎石 patch 资产，并在玩家周围以实例化网格方式铺设。生成资产使用 Blender 的 X/Y 作为 patch 平面、Z 作为石子高度，因此网格会铺在地形上，而不是竖起来。这些 patch 会对齐地形高度和法线，使用确定性放置，并避开河流、水系区域和小湖。

## User Request / 用户需求

"Start implementing the Blender-authored gravel patch mesh approach, then fix the issue where the gravel meshes stood vertical to the ground."

"好的，开始实施。你加的碎石模型垂直于地面了。"

## Scope / 范围

Add deterministic Blender asset generation, generated gravel patch assets, and runtime instanced placement. Keep the existing terrain gravel material as the base layer. Do not create a map-sized gravel model, add individual physics stones, or change unrelated water, tree, grass, player, or camera behavior.

新增确定性的 Blender 资产生成、生成的碎石 patch 资产，以及运行时实例化铺设。保留现有地形碎石材质作为底层。不创建整张地图级别的碎石大模型，不添加独立物理石子，也不改变无关的水体、树木、草、玩家或相机行为。

## Acceptance Criteria / 验收标准

- Gravel patches use `.glb` assets generated by a Blender script.
- Generated patch assets use a flat ground plane with low vertical pebble height.
- Runtime gravel placement uses `InstancedMesh` batches instead of flat alpha overlay chunks.
- Gravel patches align to terrain height and normal with a small anti-flicker offset.
- Placement remains deterministic and chunked around the player.
- Patches avoid rivers, water-system areas, and small lakes.
- `npm run build` completes successfully.

- 碎石 patch 使用 Blender 脚本生成的 `.glb` 资产。
- 生成的 patch 资产使用平铺地面形态，并只有低矮石子高度。
- 运行时碎石铺设使用 `InstancedMesh` 批处理，而不是扁平 alpha 覆盖块。
- 碎石 patch 按地形高度和法线对齐，并带有小幅防闪烁偏移。
- 放置保持确定性，并围绕玩家按方块加载。
- patch 避开河流、水系区域和小湖。
- `npm run build` 成功完成。
