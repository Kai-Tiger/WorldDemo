# Requirement / 需求

Crop the active world map to 1536 by 1536 meters.

将实际运行地图裁切到 1536 x 1536 米。

# Summary / 概要

The active terrain, vegetation generation, and player boundary now use a centered 1536m map while preserving the original 2048m heightmap sampling scale. Small lake meshes and terrain effects outside the new active bounds are skipped.

实际地形、植被生成和玩家边界现在使用居中的 1536 米地图，同时保留原 2048 米高度图采样尺度。新边界外的小湖网格和地形影响会被跳过。

# User Request / 用户需求

The user asked to crop the map to 1536x1536 after discussing performance and terrain chunk visibility.

用户在讨论性能和地形分块可见范围后，要求将地图裁切到 1536x1536。

# Scope / 范围

Update runtime map bounds, terrain chunk extent, vegetation extent, player movement bounds, and small lake filtering only. Do not modify the heightmap asset, rescale terrain coordinates, move the spawn point, move the main lake, move the waterfall, move the river, or change terrain resolution.

仅更新运行时地图边界、地形分块范围、植被范围、玩家移动边界和小湖过滤。不修改高度图资源、不缩放地形坐标、不移动出生点、不移动主湖、不移动瀑布、不移动河流，也不改变地形精度。

# Acceptance Criteria / 验收标准

- Active terrain chunk generation uses a 1536m map extent.
- Height sampling still uses the original 2048m heightmap world scale and keeps the center region.
- Grass and tree generation use the 1536m map extent.
- Player movement is clamped to the 1536m map bounds.
- Small lakes outside the new active bounds are not rendered or applied to terrain.
- The project build succeeds.

- 实际地形分块生成使用 1536 米地图范围。
- 高度采样仍使用原 2048 米高度图世界尺度，并保留中心区域。
- 草和树生成使用 1536 米地图范围。
- 玩家移动被限制在 1536 米地图边界内。
- 新实际边界外的小湖不会渲染，也不会影响地形。
- 项目构建成功。
