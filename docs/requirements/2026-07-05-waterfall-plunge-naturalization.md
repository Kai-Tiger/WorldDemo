# Waterfall Plunge Naturalization / 瀑布落点自然化

## Requirement / 需求

English: Make the waterfall base and downstream channel transition look more natural.

中文：让瀑布落点和下方河道衔接看起来更自然。

## Summary / 概要

English: The plunge foam is reshaped into a downstream-flowing broken band, and the mist particles are narrowed into a lighter vertical/downstream plume instead of a round cloud.

中文：冲潭泡沫被重塑为顺下游方向流动的破碎带，雾粒子也被收窄成更轻的竖向/下游雾柱，而不是圆形雾团。

## User Request / 用户需求

English: The user reported that the downstream river edge was not adjusted and the waterfall shape looked like a sphere.

中文：用户反馈瀑布下方河道边缘没有调整，而且瀑布形状像个球。

## Scope / 范围

English: Update only the waterfall base foam shape/material and mist particle distribution. Do not change the waterfall lip alignment, outlet stream path, terrain carving, lake geometry, downstream river path, vegetation, player behavior, lighting, textures, or unrelated pending work.

中文：仅更新瀑布底部泡沫形状/材质和雾粒子分布。不改变瀑布口对齐、出口溪流路径、地形雕刻、湖泊几何、下游河道路径、植被、玩家行为、灯光、贴图或无关待提交改动。

## Acceptance Criteria / 验收标准

English:
- Foam at the plunge pool extends into the downstream channel and softens the river edge.
- The impact mist no longer reads as a round sphere.
- The waterfall keeps a vertical falling shape with a lighter downstream plume.
- The project build passes.

中文：
- 冲潭泡沫延伸到下方河道，并柔化河道边缘。
- 冲击雾不再呈现为圆球。
- 瀑布保持竖向下落形态，并带有更轻的下游雾尾。
- 项目构建通过。
