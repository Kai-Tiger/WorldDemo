# Requirement / 需求

将模型草（grass clumps）铺设到全地图所有草地纹理可见的区域，并设计距离分级 LOD 系统以控制渲染性能。

# Summary / 概要

原有模型草仅在玩家出生点周围 15m 半径内放置。现扩展至整张 2048×2048 地图中草地纹理可见的区域（非岩石、非积雪、非河道的低地），预估理论总量约 **2500万-3100万** 丛。采用分块管理 + 距离分级 LOD + 异步渐进生成，将峰值渲染实例控制在约 **30万** 以内。

# User Request / 用户需求

> 我准备把模型草铺设到所有带有草地贴图的地方，帮我计算一下数量，以及设计一个LOD

用户选择：
- 密度保持 20 丛/m²
- 草地范围：所有非岩石/非积雪/非河道的低地区域（terrain shader 中 groundMask 高的区域）
- LOD 方案：距离分级实例化

# Scope / 范围

## 数量计算

| 项目 | 数值 |
|------|------|
| 全图面积 | 2048 × 2048 = 4,194,304 m² |
| 草地纹理可见面积（估 ~40-50%）| ~1.7M - 2.1M m² |
| 理论最大放置数（20/m²）| ~34,000,000 - 42,000,000 |
| 抖动 + 斑块过滤后（~75% 接受率）| ~25,000,000 - 31,000,000 |

## LOD 设计

| LOD 级别 | 相机距离 | 密度 | 说明 |
|----------|---------|------|------|
| LOD0 | 0 - 35m | 20 丛/m² | 完整密度，完整几何 |
| LOD1 | 35 - 100m | 5 丛/m² (1/4) | 同一几何，稀疏放置 |
| LOD2 | 100 - 200m | 1.25 丛/m² (1/16) | 同一几何，更稀疏 |
| Culled | > 200m | 0 | 不渲染 |

## 分块管理

- 分块大小：64×64m（共 32×32 = 1024 块）
- 200m 半径内活跃块数：约 48 块
- 峰值活跃实例数：~300,000 - 400,000
- 异步渐进生成：8000 step/帧，LOD0 ≈ 11 帧完成，LOD1 ≈ 3 帧，LOD2 ≈ 1 帧

## 文件变更

| 文件 | 变更 |
|------|------|
| `src/grassClumps.js` | 重构：提取共享函数/常量 (`isGrassArea`, `loadGrassModel`, `createGrassVariants`, `buildInstancedMeshes`)，保留向前兼容 |
| `src/grassZone.js` | **新增**：单分块草地管理，异步渐进生成 + LOD 切换 |

# Acceptance Criteria / 验收标准

1. **全地图草地覆盖**：玩家在任意低地（非岩石/积雪/河道）行走时，周围可见模型草地
2. **LOD 生效**：靠近时草地密集（LOD0），中距离稀疏（LOD1），远距离更稀疏（LOD2），200m 外无草地
3. **无卡顿**：草地渐进生成（每帧有步数上限），不阻塞主线程
4. **向前兼容**：原有 `createGrassClumps` / `updateGrassClumps` 导出不变
5. **构建通过**：`npm run build` 无错误
